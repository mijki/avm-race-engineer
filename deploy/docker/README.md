# Docker Deployment Assets

Status: `Planned`

This directory is reserved for containerized local and deployment packaging for
AVM Race Engineer services.

## Intended Scope

- Local multi-service bring-up for development and testing
- Linux-compatible packaging for Relay Server, Engineer Console, and PostgreSQL
- Environment examples and operational notes once services exist

## Not Yet Defined

- Production topology
- Final image boundaries
- Secret and credential handling model

F0 contains no Compose file, container image, database, or runtime
configuration. Those artifacts belong to F3 and later phase tasks.
